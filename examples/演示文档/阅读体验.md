## 把想法写成代码

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("QingYue"))
```

代码和说明放在一起，回头阅读时更容易理解。

## 阅读小贴士

1. 切换到「阅读」，让正文拥有更多空间。
2. 打开「目录」，点击标题快速定位。
3. 用 Ctrl + 滚轮调整阅读大小。
4. 在设置中选择明亮、深色、护眼或纸张主题。

## 留住下一步的思考

一份文档不必一次写完。把想到的内容先记下来，再慢慢补充标题、清单和示例。

让内容保持清晰，也给下一次打开它的自己留一点线索。

这是一份公开演示文档，不包含个人信息或真实业务数据。
